# 万象录

玄幻修仙世界观编辑工具，支持天地、时序、众生、万物四大模块、标题与正文编辑、完善程度、搜索、浏览器自动保存和 JSON 备份导入导出。

需要 Node.js 18 或更高版本，无第三方依赖。运行 `npm start`，默认使用 3000 端口；可用 `PORT=8080 npm start` 更换端口。云环境需要平台支持的服务访问方式或部署后才能从个人设备使用。

数据只保存在当前浏览器 localStorage，不会上传服务器。不同设备、浏览器和访问地址之间不会同步。清除浏览器数据会删除设定，请定期导出备份。导入会在确认后替换全部内容。当前版本没有账号、云同步或富文本编辑。

## 网站部署（GitHub Pages）

静态资源使用相对路径，支持仓库子目录。将仓库推送到 GitHub 后，在 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。以 Pages 设置页面实际显示的发布地址为准。网站公开可访问，但设定仍仅保存在各自浏览器中，不会上传到仓库。

旧版九类设定会自动归入四大模块，保留原分类字段；旧版 JSON 备份仍可导入。顶部切换模块只展示对应设定，可在编辑区更改所属模块。
