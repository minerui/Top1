# 万象弈 · 修仙自动战棋

玄幻修仙题材的单机回合制自动战斗小游戏。左右双方各有 32 格（4 行 × 8 列），每方最多上阵 6 名角色，同一种角色限一名。我方初始提供完整阵容，也可以清空后自由布阵。

- 点击角色，再点击我方空格上阵；点击已上阵角色后可移动，再点原格可撤下。
- 点击「开始论道」自动战斗；可暂停、继续、调整 1× / 2× / 4× 战速。
- 角色按速度依次行动，每三回合释放强化技能。前排优先承伤，刺修优先攻击最低气血敌人，医修治疗气血比例最低的队友，法修强化技能攻击最多三个敌人。
- 左方靠右是前排，右方靠左是前排。双方不移动，站位用于决定普通攻击的承伤顺序。
- 一方全部退场后结束，60 回合仍未分胜负则判和。点击「重新布阵」可保留阵容再次挑战，「更换敌阵」随机改变敌方站位。
- 布阵保存在当前浏览器 localStorage；不需要账号或网络服务。战斗过程不保存。

需要 Node.js 18 或更高版本，无第三方运行依赖。

```sh
npm start       # 默认 3000 端口，也支持 PORT=8080 npm start
npm test        # 战斗引擎测试
npm run build   # 更新带指纹的发布资源和入口页面
```

修改源文件后需执行构建；发布时一起提交 index.html 和新增 assets。旧指纹资源保留，供已打开的旧页面及世界观编辑器使用。云环境须通过平台支持的方式访问服务，或部署到 GitHub Pages 后使用。

原来的世界观编辑器保留在 `world.html`，可从游戏右上角「世界观藏卷」进入。其原有浏览器数据和 JSON 备份不受游戏影响。

# 万象录

玄幻修仙世界观编辑工具，支持天地、时序、众生、万物四大模块、标题与正文编辑、完善程度、搜索、浏览器自动保存和 JSON 备份导入导出。

需要 Node.js 18 或更高版本，无第三方依赖。运行 `npm start`，默认使用 3000 端口；可用 `PORT=8080 npm start` 更换端口。云环境需要平台支持的服务访问方式或部署后才能从个人设备使用。

数据只保存在当前浏览器 localStorage，不会上传服务器。不同设备、浏览器和访问地址之间不会同步。清除浏览器数据会删除设定，请定期导出备份。导入会在确认后替换全部内容。当前版本没有账号、云同步或富文本编辑。

## 网站部署（GitHub Pages）

静态资源使用相对路径，支持仓库子目录。将仓库推送到 GitHub 后，在 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。以 Pages 设置页面实际显示的发布地址为准。网站公开可访问，但设定仍仅保存在各自浏览器中，不会上传到仓库。

旧版九类设定会自动归入四大模块，保留原分类字段；旧版 JSON 备份仍可导入。顶部切换模块只展示对应设定，可在编辑区更改所属模块。

## 全新视觉版本

深墨古金界面，四个模块各有独立场景：山河、星轨、众生因缘、万象法则。画布粒子在模块切换时持续变形；尊重系统减少动态效果偏好，页面隐藏时暂停绘制。使用原有本地数据存储和备份格式。

更新界面后运行 `npm run build` 生成带内容指纹的资源并更新入口页面。发布时一并提交 assets 文件夹，旧资源保留以兼容正在打开的页面，避免浏览器缓存造成新旧文件混用。
